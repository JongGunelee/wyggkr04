XLSB 데이터 연결 준비 중…

상태·미작성 이력과 회의 요약은 서로 다른 XLSB로 관리됩니다. 웹 저장은 GitHub에 병합하고 PC 저장은 복구 대기 이력을 포함한 XLSB를 다운로드합니다.

XLSB 수동 관리 설정

수동·오프라인 사용법
  • Raw URL 또는 로컬 파일에서 두 XLSB를 불러옵니다.
  • 변경 내용은 IndexedDB 대기열에 즉시 보관됩니다.
  • 인터넷이 없거나 웹 저장이 실패하면 현재 변경 이력이 포함된 XLSB를 PC에 내려받습니다.
  • XLSB는 사용 중인 행·열만 압축 재생성하여 반복 저장으로 인한 용량 누적을 방지합니다.

GitHub API 자동 업데이트 설정

GitHub 동기화 보안·충돌 처리
  • 저장소 하나의 Contents 읽기/쓰기만 허용한 fine-grained PAT를 사용하세요.
  • 공정 관리의 encrypted-pat.json 암호문과 간편키를 조합하며 PAT 원문은 설정, TXT, XLSB에 포함되지 않습니다.
  • 각 XLSB를 최신 SHA로 다시 읽고 변경 이력을 병합한 뒤 순차 업로드합니다.
  • 충돌·권한·네트워크 오류 시 대기열을 지우지 않아 수동 복구할 수 있습니다.
