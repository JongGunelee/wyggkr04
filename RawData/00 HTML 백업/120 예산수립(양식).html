📖 건물동별 공가 수장공사 분석 시스템 매뉴얼

1. 시스템 개요 및 목적

본 시스템은 건물동별 공가 수장공사 비용 및 세대수 데이터를 기반으로 과거 3개년 이상의 데이터를 분석하여, 차기년도 예산을 과학적 근거에 기반해 수립할 수 있도록 돕는 지능형 의사결정 지원 도구입니다.

  • 엑셀 데이터의 자동 정규화 및 오타 교정을 통한 데이터 무결성 확보
  • 가중 이동 평균(WMA) 및 인플레이션 보정을 통한 예측 정확도 극대화 (N개년 확장 지원)
  • Sankey 다이어그램을 통한 자금 흐름(Fund Flow)의 직관적 시각화

2. 핵심 용어 정의

공가 (Vacant Unit) 퇴거 등으로 발생한 빈 세대로, 보수 공사가 필요한 관리 대상
수장공사 (Finishing) 도배, 장판, 도장 등 미관과 내구성을 결정짓는 마감 공사
WMA (Weighted Moving Average) 가중 이동 평균. 최신 데이터에 높은 가중치를 부여하는 예측 기법
인플레이션 보정 화폐 가치 하락(물가 상승)을 반영하여 과거 비용을 현재 가치로 환산

3. 공식 및 산술적 논리

3.1 산술 통계 모델 (Arithmetic Models)

① 단수 산술 평균 (Simple Average)

Avg = (ΣYn) / n

모든 연도의 데이터를 동일한 비중으로 계산합니다. 데이터의 변동성이 적을 때 유용합니다.

② 동적 가중 이동 평균 (Dynamic WMA)

Wᵢ = (n - i + 1) / (Σk)

선택된 모든 연도의 데이터(N개년)를 활용하되, 최근 연도에 높은 비중을 산술급수적으로 강화하여 데이터 유실 없이 예측력을 극대화합니다.

3.2 인플레이션 및 자금 흐름 논리

복리 기반 인플레이션 보정:
계산비용 = 과거비용 × (1 + r)^t

(r: 연간 물가상승률, t: 경과 연수) - 과거의 공사 비용을 목표 연도의 가치로 자동 환산합니다.

자금 흐름(Fund Flow) 적용 산식:
총 예측 예산 = ∑ (건물동별 예측 세대수 × 예측 세대당 단가)

각 건물동별로 개별 예측(WMA applied)을 수행한 후, 이를 전체로 합산하여 시스템 전체의 자금 흐름을 도출합니다.

3.3 분석 실적 년도 다중 선택 매커니즘

분석 실적 년도 다중 선택의 목적 (Purpose)

과거 데이터 중 예측의 신뢰도를 높이기 위해 특정 연도들을 선별하여 조합하는 기능입니다.
단순히 연속된 3년을 사용하는 것이 아니라, '분석 실적 년도' 메뉴에서 원하는 연도들만 체크(V)하여 불필요한 데이터(코로나 기간, 데이터 누락 연도 등 이상치)를 과감히 제외할 수 있습니다.

💡 산술적 예시 상황: 2024년, 2022년은 정상적이나 2023년 데이터가 비정상적인 경우
  • 사용자 조치: [분석 실적 년도]에서 [2024년], [2022년]만 선택하고 2023년은 해제
  • 시스템 처리: 선택되지 않은 2023년 데이터는 계산 모집단에서 완전히 제외됩니다. (0으로 처리되는 것이 아님)
  • 산술식 (단순평균 시): (Data₂₀₂₄ + Data₂₀₂₂) / 2
    (비교: 2023년을 포함하면 (Data₂₀₂₄ + Data₂₀₂₃ + Data₂₀₂₂) / 3 이 되어 평균이 왜곡됨)

선택 옵션별 상세 계산 로직

  • ① 단순 평균 (Simple Average) 선택 시 선택된 N개 연도의 데이터를 모두 합산하여 N으로 나눕니다.
    결과값 = (Y₁ + Y₂ + ... + Yn) / N
    * 모든 선택된 연도는 동일한 중요도(가중치 1:1)를 가집니다. 특정 연도에 편중되지 않은 일반적인 평균값을 원할 때 적합합니다.
  • ② 동적 가중 평균 (Dynamic WMA) 매커니즘 선택된 모든 연도를 최신순으로 정렬한 후, 분석 대상의 총 개수(n)에 따라 산술급수적 가중치(Linear Decay)를 자동 생성하여 적용합니다.
    가중치(Wᵢ) = (현시점부터의 거리) / (1부터 n까지의 합)
    * 5개년 분석 예시: [5:4:3:2:1]의 비율로 가중치 자동 할당
    (최근 1년차: 33%, 2년차: 27%, 3년차: 20%, 4년차: 13%, 5년차: 7% 반영)
    💡 논리적 근거: 고정 가중치(5:3:2) 사용 시 4년 이상 전의 데이터가 유실되는 문제를 해결하고, 모든 이력 정보를 보존하면서도 최신 트렌드를 정합성 있게 반영하기 위함입니다.

3.4 구체적인 산술 예시 (Simulation)

가정 상황: 어느 건물의 수장공사 실적이 다음과 같을 때 (물가상승률 0% 가정 시 가중치 비교)

① 3개년 분석 시 (n=3)

가중치 합계: 3+2+1 = 6

  • - 2025년(Y₀): 50% (3/6)
  • - 2024년(Y₋₁): 33% (2/6)
  • - 2023년(Y₋₂): 17% (1/6)
(V₀×0.5) + (V₁×0.33) + (V₂×0.17)

② 5개년 분석 시 (n=5)

가중치 합계: 5+4+3+2+1 = 15

  • - 2025년(Y₀): 33% (5/15)
  • - 2024년(Y₋₁): 27% (4/15)
  • - 2023년(Y₋₂): 20% (3/15)
  • - 2022년(Y₋₃): 13% (2/15)
  • - 2021년(Y₋₄): 7% (1/15)
(V₀×0.33) + ... + (V₄×0.07)

💡 데이터 비중의 논리: 년수가 늘어날수록 최근 데이터의 비중이 과도하게 쏠리지 않도록(50%->33%) 자동 조절되면서도, 가장 오래된 데이터(7%)보다는 가장 최신 데이터(33%)가 약 4.7배 더 중요하게 반영되도록 설계되어 있습니다.

5-2. 데이터 처리 및 희석 방지 시스템 (필독)

"엑셀에 연도가 있는데 왜 데이터가 없다고 하나요?" — 이 질문에 대한 명쾌한 해답입니다.

1. "데이터가 없다" vs "0원이다"의 차이

구분 상태 시스템의 처리
데이터 있음 2014년 칸에 100만원 기입 ✅ 평균 계산에 포함
데이터 없음 2014년 칸이 0원 또는 공란 ⛔ 평균 계산에서 제외 (희석 방지)

2. 희석 방지(Dilution Prevention)가 왜 필요한가요?

[초등학생도 이해하는 예시: 전학생 철수의 성적표]

  • 상황 철수는 3학년에 전학을 왔습니다. (1~2학년 성적 없음)
    3학년 시험에서 100점을 받았습니다.
  • 잘못된 계산
    단순히 3년으로 나누면?
    (0점 + 0점 + 100점) ÷ 3 = 33점 😱

    → 철수는 우등생인데 바보 취급을 받습니다. (예산 부족 발생)

  • 올바른 계산
    희석 방지 시스템 가동!
    (100점) ÷ 1(실제 다닌 기간) = 100점 👍

    → 진짜 실력이 정확히 반영됩니다. (정확한 예산 산출)

3. [실전 예시] 사용자 데이터 기준 분석

사용자님께서 업로드하신 "2014년 사택 8동 누수보수" 데이터와 같은 상황을 가정해 보겠습니다.

CASE A: [사택 8동] (2014년부터 데이터 존재)
  • 데이터 상태: 2014년 행에 '806,250원'이라는 실적(Value)이 존재합니다.
  • 시스템 처리: "이 건물은 2014년부터 운영되었구나!" → 2014년 실적을 평균 계산에 100% 반영합니다.
CASE B: [신축 기숙사] (2020년 완공 가정)
  • 데이터 상태: 엑셀 파일 전체에는 '2014년' 열이 있지만, 이 건물의 이름으로 된 2014년 행은 하나도 없습니다.
  • 시스템 처리: "이 건물은 2014년엔 없었네?" → 2014~2019년을 계산에서 '제외'합니다. (0원으로 치지 않음)
  • 결과: 건물이 생긴 2020년 이후의 데이터만으로 평균을 내어, 예산이 적게 잡히는 억울한 상황을 방지합니다.

4. 용어 상세 정의: 희석 방지 (Dilution Prevention)

희석(Dilution)이란?
물에 맹물을 타면 농도가 옅어지듯이, 통계에서 '0'이라는 숫자(맹물)가 많이 섞여서 전체 평균값(농도)을 뚝 떨어뜨리는 현상을 말합니다.
건물 관리 예산에서 희석이 발생하면, 실제 필요한 금액보다 훨씬 적은 예산이 배정되는 치명적인 문제가 생깁니다.
희석 방지 시스템의 역할
이 시스템은 사용자님이 업로드한 엑셀 데이터를 한 줄 한 줄 분석하여, "이 '0'이 진짜 0원(지출 없음)인지, 아니면 기록이 없는 기간(건물 부재)인지"를 스스로 판단합니다.
기록이 없는 기간으로 판단되면, 과감하게 통계에서 제외하여 평균값이 떨어지는 것을 막습니다.
어디에 사용되나요?
사용자님께서 [분석 실행] 버튼을 누르는 순간, 내부 연산 엔진(DomainService)의 다음 두 곳에서 즉시 작동합니다:
  1. 단순 평균(Simple Avg) 계산 시: 분모(나누는 수)를 결정할 때 사용됩니다. (10년치 평균이라도 데이터가 3년뿐이면 3으로 나눔)
  2. 가중 평균(WMA) 계산 시: 가중치 비율을 결정할 때 사용됩니다. (과거 데이터가 없으면 최신 데이터에 가중치를 몰아줌)

5-3. 논리 정합성 Q&A (필독)

Q1 왜 '다중 연도'를 선택하면 슬라이더(10년)가 적용되지 않나요?

"사용자의 명확한 선택(Explicit Selection)을 최우선으로 존중하기 때문입니다."

만약 선생님께서 [2024년, 2025년] 2개를 콕 집어 선택하셨다면, 시스템은 "아, 다른 과거 데이터는 다 필요 없고 딱 이 2년치만 평균을 내고 싶으시구나!"라고 판단합니다.
이때 슬라이더(10년)를 강제로 적용하면, 2024의 과거 10년 + 2025의 과거 10년이 뒤섞여서 원치 않는 데이터가 포함되는 문제(오염)가 발생합니다.
따라서 다중 선택 시에는 슬라이더를 무시하고 선택하신 연도만 100% 반영합니다.

Q2 그럼 슬라이더(과거 데이터 깊이)는 언제 쓰나요?

"단일 연도(기준)를 선택했을 때 사용합니다."

[2025년] 하나만 선택하고 슬라이더를 5년으로 두시면,
시스템은 "2025년을 기준으로 과거 5년치(2021~2025)를 조회해서 평균을 내라"는 명령으로 이해하고 자동으로 과거 데이터를 끌어옵니다.
즉, [단일 선택 = 기준점 설정], [다중 선택 = 데이터셋 직접 지정]으로 이해하시면 편합니다.

📊 예측 방법이란?

과거 데이터를 기반으로 미래 예산을 예측하는 방식을 선택합니다.

✓ 단순 평균

최근 3년 데이터의 산술 평균을 계산합니다.
예: (2023 + 2024 + 2025) ÷ 3

✓ 가중평균 (5:3:2)

가중평균: 최근 연도 데이터에 더 높은 가중치를 부여합니다.
예: 2025년×50% + 2024년×30% + 2023년×20%

💡 사용 팁

최근 데이터의 비중을 높이고 싶다면 가중평균이 더 정확합니다.

가중평균: 최근 데이터에 더 높은 가중치를 부여하여 예측

📈 인플레이션 보정이란?

과거 비용을 현재 물가 수준으로 환산하여 보다 정확한 예측을 합니다.

계산 공식

현재가치 = 과거비용 × (1 + 인플레율)^경과년수

예시 (5% 설정 시)

2023년 1억원 → 현재가치 1.1억원
(1억 × 1.05² = 1.1억)
